# Undo does not guarantee reversibility

Undo provides an evidence-based Reversibility Assessment and preserves it in an Undo Record, but it does not guarantee that a merchant will accept a return or reimburse the buyer. Calling the assessment an "undo contract" would imply that Undo underwrites merchant behavior, changing the product into a return-guarantee or insurance-like business with materially different financial, legal, and operational obligations.
