# Undo

Undo helps a buyer compare the evidenced cost and uncertainty of reversing equivalent purchase Offers before payment.

This repository currently contains the issue #2 walking skeleton: a seven-stage Reversibility Assessment for the supported Sennheiser HD 560S Product. Deterministic fake Senso, OpenAI, and Prava adapters make the full decline path repeatable without presenting fixture data as live merchant data.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run typecheck
npm run lint
npm test
npm run build
```
